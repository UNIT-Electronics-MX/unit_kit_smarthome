## Descripción

El **Kit SmartHome de UNIT Electronics** (AR4623) es una casa didáctica para aprender ensamble, electrónica y programación. La tarjeta **UNIT DualMCU ONE** combina ESP32 y RP2040; el kit añade sensores, actuadores, comunicación I²C y una aplicación móvil para Android. Esta referencia resume el manual de usuario **V1.1.0 del 16 de febrero de 2026**. Para el montaje paso a paso y la orientación de cada cable, consulte el [manual completo](<assets/I2D-Manual de usuario - Kit SmartHome-280926-171843.pdf>).
